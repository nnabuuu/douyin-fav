# 单条字幕提取界面（`/`) — 功能描述(给 Claude Design)

> **先读 `docs/project-overview.md`** —— 产品是什么、用户是谁、整体流程、架构铁律、术语表。下面只写这个界面专属的内容。

后端**已就绪**,`/` 已有一个能用的朴素版。本文档让你**重做/美化前端**:一个「贴链接 → 直接拿到这条视频文字稿」的页面。纯静态页 + 调后端 JSON API。

## 项目背景(精简,完整见 project-overview.md)

- **产品**:本地自托管工具,把抖音视频转成文字稿(有字幕取字幕,没有用本地 whisper 语音识别)。
- **这个界面是哪条操作**:**即取即得的单条转录**,和「自动同步到 Notion」是**两条独立的路**:
  - 本页 = 用户**主动贴一个链接,马上在网页里看到这一条的文字稿**,不写 Notion、不需要任何 Notion/收藏夹配置。
  - 自动同步(见 `config-ui-spec.md`)= 服务后台定时扫收藏夹批量写进 Notion。
- **这是最面向用户、最可分享的一页**:你把服务跑起来,同网段的别人打开这页就能用(给链接拿字幕)。语气应比那几个运维页更友好、干净。
- **架构铁律(影响设计)**:抓取要登录态、要开浏览器、无字幕的要本地语音识别——这些**都在后端宿主机发生**,本页只**提交任务 + 轮询结果**。新视频的转写是**分钟级**(ASR),所以是异步任务 + 排队,不是同步等待。
- **用户/语气**:中文;面向「我就想要这条视频的文字」,简单直接。

## 后端 API(已实现,直接调)

同源。若服务端设了 `TOKEN`,所有 `/api/*` 需带 `?token=<秘钥>`。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/jobs` | body `{url}`,提交一条;返回 `{id, status:"queued"}`(缺 url → 400 `{error}`) |
| GET | `/api/jobs/:id` | 轮询任务 |

`GET /api/jobs/:id` 返回:
```ts
{
  status: "queued" | "running" | "done" | "error",
  position?: number,   // 排队时:1 = 正在处理;否则你排第几
  ahead?: number,      // 前面还有几个
  log: string[],       // 处理过程的提示(最后一条最有用,如「无字幕轨,下载+ASR…」)
  result?: VideoResult,// done 时
  error?: string       // error 时
}
```
`VideoResult`:
```ts
{
  platform: "douyin",
  videoId: string,
  title: string,        // 文案首行
  desc: string,         // 文案(含话题标签)
  author: string,       // 作者昵称
  transcript: string,   // 口播逐字稿
  source: "subtitle" | "asr",  // 字幕轨直接取 / 本地语音识别
  cached: boolean       // true = 之前转过,秒回
}
```

**输入支持**(后端自动识别):`https://www.douyin.com/video/<id>`、带 `?modal_id=<id>` 的链接、`v.douyin.com` 分享短链、纯数字 id。

## 界面要做的

### 输入
- 一个醒目的输入框 + [提取] 按钮(回车也提交)。placeholder 举例链接形式。
- 提交 → `POST /api/jobs` → 拿 `id` → 开始轮询 `GET /api/jobs/:id`(每 2s)。

### 进度(按 status)
- **queued**:`排队中 — 第 {position} 位`(`ahead>0` 时补「前面还有 {ahead} 个」)。
- **running**:`处理中…` + 显示 `log` 最后一条(让用户知道在下视频/在转写)。
- 给**预期管理**:新视频要本地转写,**可能几分钟**,提示「可以放着,转完会出来」;`cached`/字幕轨会很快。

### 结果(done)
- **来源徽标**:`字幕轨`(绿,秒级)/ `ASR`(橙,刚转写完);`cached` 时标「缓存」。
- **作者 + 原视频链接**(可点回 `https://www.douyin.com/video/<videoId>`)。
- **文案**区块(`desc`)。
- **口播逐字稿**区块(`transcript`)——这是主角,**排版要好读**(字号/行距/可滚动),长文要舒服。
- 操作:**[复制逐字稿]**、**[复制全部]**、**[下载 .txt/.md]**。

### 错误(error)
把 `error` 显示清楚,并给出路:
- 「没有可用 token」→ 提示去 **token 管理界面**扫码登录(给链接)。
- 「验证码」→ 提示去宿主机弹出的浏览器窗口手动过一下,再重试。
- 「不支持的链接」→ 提示支持的链接形式(目前抖音;bilibili 待支持)。
- 其它(视频私有/不存在等)→ 原样展示 + [重试]。

### 可选增强
- **本次会话的任务列表/历史**:允许连续贴多条,各自显示状态(因为后端串行排队,后提交的会显示排在第几位)。比单次替换更顺手。

## 行为 / 边界
- **串行排队**:同时只处理一条,所以会有「第 N 位」。UI 要把排队讲清楚,别让用户以为卡住。
- **轮询节制**:done/error 后停止轮询;离开页面停掉。
- **重复提交同一条**:后端有缓存,`cached:true` 秒回——可直接展示,不必特殊处理。
- `?token=` 门禁:URL 带了就所有请求都带上。

## 状态语义
- `source=subtitle`:视频自带字幕,直接取,快。
- `source=asr`:无字幕,本机 whisper 转写,慢(分钟级)。
- `cached=true`:以前转过,本次直接读缓存。

## 设计提示
- 这是**最像「产品」的一页**(别人会直接用):干净、友好、可分享,移动端也要能看(同网段可能用手机开)。
- 把「贴链接 → 出文字」做成爽快的主流程;逐字稿阅读体验是重点(好排版 + 复制/下载)。
- 与 `/setup`、token 管理、`/config` 同产品,但这页可以更「面向消费者」一点;保持同一套基础视觉。
- 中文;深色加分。

## 不在范围
- 不写 Notion、不碰收藏夹/调度配置(那是自动同步那条路,见 config-ui-spec)。
- 不实现抓取/转写逻辑、不渲染二维码、不碰文件命令——全在后端。
- token 的增删管理在 token 管理界面,本页最多在「没 token」时给个跳转。

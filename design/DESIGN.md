# 即见 Jijian · 抖音收藏夹 → Notion 文字稿 · 前端设计文档

本地自托管工具的前端。后端已就绪,前端是薄壳:读写配置、提交任务、轮询状态。本文档说明四个页面、它们如何串联、以及所用设计系统。

---

## 一、产品与架构铁律(影响设计)

- **产品**:把用户抖音收藏夹的视频转成文字稿,自动同步进 Notion;也支持单条即取即得。
- **薄壳原则**:真正干活的是本机服务,**自带定时器在后台跑**(不依赖网页开着)。网页只做「改配置 + 看/控同步 + 提交单条任务」。
- **扫码不在网页内**:登录在宿主机弹出的 Chrome 窗口完成,**网页不渲染二维码**,只发起 + 轮询状态。
- **异步任务**:新视频转写是分钟级(本机 whisper),所以是排队 + 轮询,不是同步等待。
- **门禁**:服务端若设了 `TOKEN` 环境变量,所有 `/api/*` 需带 `?token=<秘钥>`;URL 带了就所有请求都带上。

## 二、四个页面与串联

四个页面共享一套**左侧边栏导航**(248px),互相可跳转,读作同一个产品。

```
┌─────────┬──────────────────────────────┐
│ 即见     │                              │
│         │                              │
│ 提取字幕 │         主内容区              │
│ 自动同步 │                              │
│ Token   │                              │
│ 安装向导 │                              │
│         │                              │
│ ●本地运行│                              │
└─────────┴──────────────────────────────┘
```

| 文件 | 路由 | 角色 | 一句话 |
|---|---|---|---|
| `Transcribe.dc.html` | `/` | 面向用户 | 贴链接 → 拿这条文字稿(可单条同步 Notion) |
| `Config.dc.html` | `/config` | 运维 | 自动同步开关 + 节奏 + 收藏夹 + Notion + ASR |
| `Tokens.dc.html` | — | 运维 | 抖音登录态 token 池管理(扫码添加 / 验证 / 删除) |
| `Setup Wizard.dc.html` | `/setup` | 引导 | 装好后的依赖检查 + 首次接通向导 |

**两条独立的路**:
1. **即取即得(Transcribe)** — 用户主动贴链接,网页里直接看这一条;默认只看,可选「同步到 Notion」单条写入。
2. **自动同步(Config)** — 服务后台定时扫收藏夹,批量写进 Notion。

**跨页跳转**:
- Transcribe 报「没有可用 token」错误 → 引导到 **Token 管理**扫码登录。
- Config / Setup 里的收藏夹与节奏互为简化版与细调版。

## 三、各页面要点

### 提取字幕 `/`(最像「产品」、可分享)
- 醒目输入框 + [提取](回车也提交)。
- 状态机:`queued`(第 N 位)→ `running`(显示 log 最后一条)→ `done` / `error`。
- 结果:**来源徽标**(`字幕轨` 绿/秒级、`ASR` 橙/刚转写、`缓存` 灰)、作者 + 原视频链接、文案、**口播逐字稿**(主角,大字号宽行距、可滚动)。
- 操作:复制逐字稿 / 复制全部 / 下载 .md / **同步到 Notion**(单条按需写入)。
- 错误分流:无 token → 去 Token 管理;验证码 → 去宿主机窗口;不支持的链接 → 提示形式。
- 本次会话历史(连续贴多条)。

### 自动同步 `/config`(信息密度高、分组清晰)
- **同步控制面板**(深色,放最上):自动同步主开关(同时动持久 `enabled` 与内存 `scheduled`)、实时状态点、下次大致时间、**立即同步一轮**(`running` 时禁用)。
- **上一轮结果**:新增 / 跳过 / 失败三色计数;失败明细可折叠。
- **收藏夹**:列表编辑器,增删改,校验含 `douyin.com`。
- **Notion**:token(password)+ databaseId,预填回填、幂等;不填则只转写不写 Notion。
- **节奏**:间隔(分钟,≥1)、每轮上限(=每轮最多**新转写**几条,缓存不占额度,带 tooltip)。
- **ASR**:whisper 模型下拉(tiny…turbo),默认 turbo。
- 脏标记:有未保存改动时显示「保存改动」。

### Token 管理(状态第一)
- token 卡列表:**状态徽标**(valid 绿 / invalid 红 / unknown 灰 / logging_in 蓝+脉冲)、账号昵称 + uid、平台、相对时间、`failureCount>0` 警告。
- 行内操作:验证(转圈)、删除(确认)。
- 顶部:刷新、+ 添加 token。
- **添加流程**:选平台(默认抖音)+ 备注 → 弹窗「请在本机 Chrome 窗口扫码」→ 轮询 → 变绿成功 / 超时重试 / 取消。
- 空状态引导加第一个。

### 安装向导 `/setup`
- 依赖检查(Node / Chromium / ffmpeg / whisper),进度条,逐项可展开装法。
- 抖音登录、Notion、收藏夹与定时的简化接入,最后「立即同步一轮」。

## 四、设计系统(即见 Jijian · Editorial Zen)

### 颜色(三层表面 + 静音语义色)
| 用途 | 变量 | 值 |
|---|---|---|
| 主表面 / 卡片 / 更深 | `--surface` / `--surface-elevated` / `--surface-subtle` | `#fafbfc` / `#ffffff` / `#f0f2f4` |
| 文字 主 / 次 / 弱 | `--ink` / `--ink-secondary` / `--ink-muted` | `#1a2332` / `#536471` / `#8899a6` |
| 权威(CTA/深色区/用户气泡) | `--navy` | `#1a2332` |
| 交互强调(链接/焦点/激活) | `--accent` | `#4a7c6f` 青绿 |
| 语义 绿/琥珀/红/蓝 | `--green` `--amber` `--red` `--blue` | 均为静音色,各配 `-bg` |

### 字体
- **Inter**(正文/UI)+ **Noto Serif**(品牌「即见」、引言)+ **JetBrains Mono**(代码/ID/token)。
- Serif 严格限量:仅品牌字、哲学引言。其余皆 Inter。
- 区块标签:英文大写 + `letter-spacing:.08em`(如 `TRANSCRIBE` `AUTO SYNC`)。

### 间距 / 圆角 / 阴影
- 4px 基准。卡片圆角 `14px`、按钮/输入 `8–10px`、徽标 `6px`、pill `100px`。
- **默认无阴影**;hover 才浮现阴影 + 边框加深(空间反馈)。
- 卡片:`surface-elevated` 底 + 1px `border-subtle`,padding 18–22px。

### 动效
- 全局 `0.2s ease`,transform `0.15s`,不用 `ease-in-out`。
- 仅几处有意义的动:转圈(spin)、状态点脉冲(pulse)、开关滑块、刷新图标旋转。**无弹跳、无装饰动效**。

### 图标
- 全部手写 inline SVG,stroke 2px,`currentColor`。无图标字体库、无 emoji(UI 内)。
- 状态用 6–8px 圆点;skill/平台图标用圆角方块 + 单字。

## 五、技术形态

- 每页是一个 **Design Component**(`*.dc.html`),浏览器直接打开,共享 `support.js` 运行时。
- 样式**全内联**,无外部样式表;颜色/字体走 `:root` CSS 变量(对齐设计系统 token 名)。
- 逻辑在 `class Component extends DCLogic`:状态机、轮询模拟、列表编辑、脏标记等。
- 当前为**设计稿**:交互用本地 state + 定时器模拟后端;接真实后端时把模拟换成对应 `/api/*` 调用即可(API 见各 spec)。

---

## 六、不在范围(全在后端)

- 不实现抓取 / 转写 / 写 Notion 的逻辑;不渲染二维码;不碰文件 / 命令行。
- token 的 cookie 明文不经网页(后端只存档案目录路径)。
- bilibili 为占位平台,前端留位、暂不可选。
